With command <code>disas main</code> we can have a look into assembly code of main function. There we can have a look, what functions the program is calling during the run. What struck me, that function <code>check_password</code> wasn't called in the program.
It seems that <code>call mAsdf3a</code> is where the actual password check is happening.

<img width="1301" height="442" alt="Screenshot From 2026-09-22 23-50-04" src="https://github.com/user-attachments/assets/3af02911-6969-4df5-9953-f33509659f41" />

When program is stopped in debugger, user can manipulate value of the function program is trying to run in Assembly. In this case we change the value of <code>eax</code> memory slot to 1. This is the line that compares the user input to stored password, value 0 will not let the program to proceed, value 1 will proceed to flag.
