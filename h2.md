The assignment brief gave out that the table is called “pins” with columns called “pin” and “password”.

I used UNION payload, which I learned from PortSwigger lab courses. 
In SQL UNION function allows user to write second query and glue it with previous one, so the system sends additional query to the database.

I got the password with following payload:
<code> ' UNION SELECT password FROM pins -- </code> 

With <code> group_concat </code> function, it's possible to retrieve everything stored in the specific column as a string.
<code> ' UNION SELECT group_concat(password) FROM pins -- </code>

In original code variable <code> pin </code> got it's value from the input of the form on the web interface, when the user input is integrated directly (<code> + pin + </code>) into SQL query, it opens vulnerability for SQL injections.
