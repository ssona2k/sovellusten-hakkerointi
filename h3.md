## h3 No Strings Attached (Tero)

### a) 

First of all, it's good to read the README when there's one.
As I'm running ARM machine, there's instructions how to compile the program for arm64 architechture. 

After recompiling program (<code>make clean; make</code>) I ran command <code>strings passtr</code>, that revealed the FLAG and the password <code>sala-hakkeri-321</code>.
Neater output can be achieved by using <code>grep</code> with pipes. Command <code>strings</code> prints the printable character sequences that are at least 4 characters long (or the number given with the options below) and are followed by an unprintable character (src: Debian manpages).
