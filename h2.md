First I manipulated in browser dev-tools input forms type from "numbers" to "text" so the form would accept the payload.

The assignment brief gave out that the table is called “pins” with columns called “pin” and “password”.

I used UNION payload, which I learned from PortSwigger lab courses. 
In SQL UNION function allows user to write second query, and glue it to the first one, so the system sends additional query to the database.

I got the password with following payload:
<code> ' UNION SELECT password FROM pins -- </code> 

Also with <code> group_concat </code> functio, it's possible to retrieve everything stored in the specific column as a string.
<code> ' UNION SELECT group_concat(password) FROM pins -- </code>
