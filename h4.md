<img width="1777" height="833" alt="Screenshot From 2026-09-16 01-07-05" src="https://github.com/user-attachments/assets/2115006a-df0a-49a6-9251-e53020c8ce7d" />

It looks like <code>char</code> datatype is for the the password and <code>local_28</code> is the variable containing it. There's allocated 32 byte lenght for the password, so it can contain 31 charecters as it needs the <code>\0</code> terminating byte in the end.

The program uses <code>strcmp</code> function to check the password. <code>strcmp</code> results <code>0</code> if the both strings are matching.
Variable <code>iVar1</code> is storing comparison result of variable <code>local_28</code> and password "piilos-AnAnAs.
If <code>iVar1</code> equals <code>0</code>, the program prints the flag. 

### c)

Click on the <code>if</code> loop in the decompiled view, points into <code>JNZ</code> in Assembler listing. At this point I had to ask Claude for instructions, as I'm not familiar with Assembler.
<code>JNZ</code> stands for "Jump if not zero".
