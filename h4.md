It looks like <code>char</code> datatype is for the the password and <code>local_28</code> is the variable containing it. There's allocated 32 byte lenght for the password, so it can contain 31 charecters as it needs the <code>\0</code> terminating byte in the end.

The program uses <code>strcmp</code> function to check the password. <code>strcmp</code> results <code>0</code> if the both strings are matching.
Variable <code>iVar1</code> is storing comparison result of variable <code>local_28</code> and password "piilos-AnAnAs.
If <code>iVar1</code> equals <code>0</code>, the program prints the flag.

<img width="2833" height="1220" alt="Screenshot From 2026-09-16 13-20-55" src="https://github.com/user-attachments/assets/53d5ee2a-a4f8-4ad8-ab24-c65c42520519" />

This is the decompiled output in Ghidra of 02. It looks very similar to the
first program, but there is a <code>for</code> loop inside the <code>if</code>.

I used Claude to help me understand the loop. On each iteration it takes the
character at index <code>local_c</code> of <code>"password1"</code>, subtracts
1 from its ASCII value, and compares the result against the character at the
same index of the input. So the expected input is "password1" shifted down by one byte per character p -> o, s -> r and so on, giving the actual password o`rrvnqc0.
