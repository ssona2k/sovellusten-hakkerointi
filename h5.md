### Lab2

File lacks DWARF debugging symbols. 
We can still see list of the functions used in the program with command <code>info functions</code>.

There we see four interesting functions:
   - main
   - check_password
   - mAsdf3a
   - EaseEAs 

<img width="606" height="585" alt="image" src="https://github.com/user-attachments/assets/43027592-2f18-4425-9c68-a8baf1d5d138"/>

With command <code>disas main</code> we can have a look into assembly code of main function. There we see, what functions the program is calling during the run. What struck me, that function <code>check_password</code> wasn't called in the program.

It seems that <code>call mAsdf3a</code> is where the actual password check is happening.
The decision happens in lines <code>dec eax</code> and <code>jne</code>(jump if not equal). After <code>dec eax</code> <code>jne</code> jumps if the result is not zero. The logic is:

   - <code>eax</code>  = 1 -> becomes 0 -> no jump -> falls through to <code>call EaseEAs</code> -> flag
   - any other value -> non-zero -> jump -> fail

Setting breakpoint to <code>main+133</code>. +133 refers to 133 bytes from the start of main (landing it on the <code>dec eax</code> instruction).

The program stops on the line <code>0x5105</code>, that's just after the password input. 

<img width="1301" height="442" alt="Screenshot From 2026-09-22 23-50-04" src="https://github.com/user-attachments/assets/3af02911-6969-4df5-9953-f33509659f41"/>

Because the password was invalid, <code>mAsdf3a</code> returned a value other than 1 in the <code>eax</code>
register (the correct password would make it return 1). The comparison happened
inside <code>mAsdf3a</code> function, the <code>dec eax</code> / <code>jne</code> here only tests that return value.

While running is paused, we overwrite eax with <code>set $eax = 1</code>. Now <code>dec eax</code> gives 0,
<code>jne</code> doesn't jump, and the program falls through to <code>call EaseEAs</code>, which prints the flag by
bypassing the check without ever recovering the real password.
